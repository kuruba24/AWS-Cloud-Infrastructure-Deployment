# AWS Cloud Infrastructure Deployment

## Project Overview

This project demonstrates the deployment of a secure, scalable, and highly available cloud infrastructure using Amazon Web Services (AWS). The project focuses on designing cloud networking, deploying compute resources, implementing storage solutions, monitoring system performance, and automating deployments using CI/CD services.

---

## Objectives

- Design a secure AWS cloud environment.
- Deploy EC2 instances within a custom VPC.
- Configure IAM users, roles, and security groups.
- Store application data using Amazon S3.
- Implement monitoring using Amazon CloudWatch.
- Configure Auto Scaling and Elastic Load Balancer.
- Automate deployments using AWS CodePipeline, CodeBuild, and CodeDeploy.
