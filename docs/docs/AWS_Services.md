# AWS Services Used

## Amazon EC2
Used to launch and manage virtual servers.

## Amazon VPC
Provides an isolated virtual network.

## Amazon S3
Stores project data and application files.

## IAM
Controls user authentication and permissions.

## CloudWatch
Monitors AWS resources and generates alarms.

## Elastic Load Balancer
Distributes traffic among EC2 instances.

## Auto Scaling
Automatically increases or decreases EC2 instances based on demand.

## AWS CodePipeline
Automates software delivery.

## AWS CodeBuild
Builds application source code.

## AWS CodeDeploy
Deploys applications to EC2 instances automatically.
