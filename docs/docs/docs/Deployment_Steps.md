# Deployment Steps

1. Created a custom VPC.
2. Configured public subnet.
3. Attached Internet Gateway.
4. Created Route Table.
5. Configured Security Groups.
6. Launched Amazon EC2 Instance.
7. Connected to EC2 using SSH.
8. Configured IAM roles.
9. Stored files in Amazon S3.
10. Enabled CloudWatch Monitoring.
11. Configured Auto Scaling Group.
12. Created Elastic Load Balancer.
13. Built CI/CD pipeline using Code Pipeline, Code Build and Code Deploy.
